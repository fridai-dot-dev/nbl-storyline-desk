# Customer voice

Code this week's reviews. For each review, give its sentiment, every theme it mentions with a short verbatim quote as evidence, whether it names a staff member, and whether it raises food safety. Use the `theme-coding` skill for the theme list and the rules.

Return only the structured result. Code, not you, counts theme shares by store, region and network for the week, the last month and the last 3 months.
