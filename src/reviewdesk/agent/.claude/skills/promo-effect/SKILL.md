# Promotion and change effects

## Method

1. **Baseline.** Compare the promotion weeks with the same stores' last 3 months, by hour and channel. A single week against a single week is not a baseline.
2. **Comparison stores.** Where some stores didn't run the promotion, compare with stores of the same format (standalone, food court, petrol-station kiosk) in the same region.
3. **Context.** Check weather, school and public holidays and local events for the same days before reading anything into a change.
4. **Side effects.** Look past redemptions: waits, wait-time complaints, stock-outs, waste and labour hours in the hours the promotion loaded.
5. **Size.** Report the change in the measure's own units with its baseline, for example "1.8 items per sale against 2.2 over the last 3 months". Never report a percentage without the counts behind it.

## Labels

- **coincides with:** the change and the promotion happened together; nothing else was checked.
- **consistent with:** the baseline and context were checked and fit this explanation, but other explanations are not ruled out.
- **tested:** a comparison against matched stores or a planned trial was run, and the result is stated with its sample size.

Never write "caused", "drove" or "because of". Suggest the trial that would move a claim from "coincides with" to "tested".
